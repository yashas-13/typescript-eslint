# AST Specification

The following auto-generated documentation describes the Abstract Syntax Tree (AST) generated by [`@typescript-eslint/typescript-estree`](../TypeScript_ESTree.mdx) for parsers such as [`@typescript-eslint/parser`](../Parser.mdx).

## Recognizing AST nodes in code

For example, a generic function call can contain a `TSTypeParameterInstantiation` node for its explicit type arguments:

```ts
declare function identity<T>(value: T): T;

identity<string>("hello");
```

The `<string>` part of the call is the type-argument instantiation. By contrast, the `<T>` in the function declaration is a `TSTypeParameterDeclaration`: the former supplies type arguments, while the latter declares type parameters. The AST spec package includes a [fixture for a generic function type argument](https://github.com/typescript-eslint/typescript-eslint/tree/main/packages/ast-spec/src/special/TSTypeParameterInstantiation/fixtures/type-argument-generic-function-type) that can be used to inspect the corresponding AST snapshot.
